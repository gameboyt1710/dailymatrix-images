# The Daily Matrix - Image Hosting for Twitter/X

User guide:  

-Website:  
Go to thedailymatrix.com, upload image, copy given url,  
paste url in twitter post, maybe wait for preview to load because twitterbot is slow, post!  
Tip: put the url for the image as the last bit in your post so the text doesn't visually show, just the preview.  

-Extension:  
For now extension isn't on any public marketplaces yet, so you'll have to set it up manually.  

Quick set-up guide:  
Open a terminal/shell/cmd/powershell/... (on mac: ⌘command+space, type "terminal", enter)  
Execute the following:
```
git clone https://github.com/gameboyt1710/image-extension
```
Then go into your browser of choice, head over to chrome://extensions (this should redirect to your browsers extension page)  
Switch on "Developer mode" in the top right corner  
Click "Load unpacked" in the top left corner  
Search for and select the folder "browser-extension" (usually in //Users/(your name)/)  

Now you can simply go to twitter and you should see something like this in your post composer:  
<img width="343" height="93" alt="Screenshot 2025-12-29 at 12 37 18" src="https://github.com/user-attachments/assets/9d712d90-c930-4087-96e8-d64736682d1c" />  
I'd recommend basically always having "Add paddin" turned on, this just makes sure your image doesn't get cropped.  
To use it, simply write whatever you wanna write as usual and when you want to embed an image, click the little speaker button (place holder icon),  
this should bring up a file selector, simply pick the image you want to embed and load it,  
the tool will automatically convert it into a link and add it to your post, again maybe you'll have to wait a bit for the preview to load, but that's it!

Daily Matrix Extension Icons

Right-click each icon below and "Save image as..." to download

How to use these icons:

  1. Right-click each icon above
  2. Select "Save image as..."
  3. Save as icon16.png, icon48.png, and icon128.png
  4. Place them in the browser-extension folder
  5. Reload the extension in your browser

Or use a design tool: Create custom 128x128 icon and use a tool like Icon Editor to generate all sizes.
